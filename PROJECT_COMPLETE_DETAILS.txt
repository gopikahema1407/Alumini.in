PROJECT OVERVIEW
================================================================================

AluminiX is a comprehensive career and networking platform designed specifically
for Karpagam Institute of Technology (KIT). It connects students with alumni
mentors, provides AI-powered career guidance, enables social networking features,
and facilitates job opportunities and professional growth.

Platform Status: FULLY OPERATIONAL
Launch Date: August 23, 2026
Current Version: 2.0 (With AI & Social Features)
Technology Stack: Python (Flask) + JavaScript + Supabase + HuggingFace AI

DATABASE SCHEMA
================================================================================

Tables (11 core tables):

1. users
   - id (UUID, Primary Key)
   - email (String, Unique)
   - role (Enum: student, alumni)
   - full_name (String)
   - department (String)
   - institution (String)
   - profile_picture_url (String)
   - linkedin_url (String)
   - github_url (String)
   - bio (Text)
   - created_at (Timestamp)
   - updated_at (Timestamp)

2. posts
   - id (UUID, Primary Key)
   - user_id (UUID, Foreign Key)
   - title (String)
   - description (Text)
   - type (Enum: announcement, certificate, job_opening, career_update)
   - image_url (String)
   - likes_count (Integer)
   - comments_count (Integer)
   - created_at (Timestamp)
   - updated_at (Timestamp)

3. messages
   - id (UUID, Primary Key)
   - sender_id (UUID, Foreign Key to users)
   - recipient_id (UUID, Foreign Key to users)
   - message_text (Text)
   - is_read (Boolean)
   - created_at (Timestamp)
   - read_at (Timestamp)

4. notifications
   - id (UUID, Primary Key)
   - user_id (UUID, Foreign Key)
   - actor_id (UUID, Foreign Key to users)
   - type (Enum: message, request, like, comment, mention)
   - title (String)
   - description (Text)
   - related_object_id (UUID)
   - is_read (Boolean)
   - created_at (Timestamp)

5. mentorship_requests
   - id (UUID, Primary Key)
   - student_id (UUID, Foreign Key)
   - alumni_id (UUID, Foreign Key)
   - status (Enum: pending, accepted, rejected)
   - message (Text)
   - created_at (Timestamp)
   - updated_at (Timestamp)

6. user_connections
   - id (UUID, Primary Key)
   - user_id_1 (UUID, Foreign Key)
   - user_id_2 (UUID, Foreign Key)
   - connection_type (Enum: mentor, mentee, connection)
   - created_at (Timestamp)

7. jobs
   - id (UUID, Primary Key)
   - posted_by (UUID, Foreign Key)
   - title (String)
   - company (String)
   - department (String)
   - description (Text)
   - location (String)
   - salary (String)
   - job_type (Enum: full-time, part-time, internship, contract)
   - created_at (Timestamp)
   - expires_at (Timestamp)

8. roadmaps
   - id (UUID, Primary Key)
   - user_id (UUID, Foreign Key)
   - title (String)
   - target_role (String)
   - roadmap_content (Text)
   - progress_percentage (Integer)
   - created_at (Timestamp)
   - updated_at (Timestamp)

9. chat_messages
   - id (UUID, Primary Key)
   - user_id (UUID, Foreign Key)
   - message_text (Text)
   - response_text (Text)
   - context (Text)
   - created_at (Timestamp)

10. posts_likes
    - id (UUID, Primary Key)
    - post_id (UUID, Foreign Key)
    - user_id (UUID, Foreign Key)
    - created_at (Timestamp)

11. posts_comments
    - id (UUID, Primary Key)
    - post_id (UUID, Foreign Key)
    - user_id (UUID, Foreign Key)
    - comment_text (Text)
    - created_at (Timestamp)

Performance Optimizations:
- Indexes on user_id, created_at, status fields
- Foreign key constraints for data integrity
- RLS (Row Level Security) policies for data privacy
- Connection pooling for efficiency
- Query optimization with proper joins
- Pagination support (limit/offset)


AI INTEGRATION DETAILS
================================================================================

AI Provider: HuggingFace Inference API

Models Used:

1. Llama 3 (8B Instruct)
   - Model ID: meta-llama/Meta-Llama-3-8B-Instruct
   - Use Case: General tasks, roadmap generation, complex reasoning
   - Max Tokens: 8,192
   - Strengths: Long-form responses, detailed explanations, nuanced reasoning
   - Response Time: 4-10 seconds

2. Mistral 7B Instruct
   - Model ID: mistralai/Mistral-7B-Instruct-v0.1
   - Use Case: Chat, mentoring, matching, quick responses
   - Max Tokens: 8,192
   - Strengths: Fast responses, good instruction following, conversational
   - Response Time: 2-5 seconds

3. Sentence Transformers (Embeddings)
   - Model ID: sentence-transformers/all-MiniLM-L6-v2
   - Use Case: Semantic similarity for matching (future implementation)
   - Strengths: Lightweight, fast embeddings for similarity
