================================================================================
WHAT TO DO IF SOMETHING DOESN'T WORK
================================================================================

Problem: "Mentorship request not sending"
─────────────────────────────────────────
Solution:
1. Check console: Press F12 → Console tab
2. Look for red error messages
3. Check that you're logged in as a student
4. Try again from Alumni Directory page
5. Check server logs in terminal

Problem: "Like button not working"
──────────────────────────────────
Solution:
1. Refresh page (Ctrl+F5 for hard refresh)
2. Check browser console for errors
3. Make sure you're logged in
4. Try clicking like on different post
5. Check server logs for backend errors

Problem: "Comment prompt doesn't appear"
────────────────────────────────────────
Solution:
1. Check if browser blocks popups (check address bar)
2. Try using different browser
3. Refresh page and try again
4. Check console for JavaScript errors
5. Verify server is responding

Problem: "Counts not updating after action"
───────────────────────────────────────────
Solution:
1. Refresh page to reload data
2. Wait 2-3 seconds before refreshing
3. Check database connection
4. Try logging out and back in
5. Check server logs for errors

General Troubleshooting:
1. Open browser console: F12
2. Go to Console tab
3. Look for error messages (red text)
4. Copy error and check logs
5. Restart server: Ctrl+C then python app.py

HOW TO REPORT ISSUES
================================================================================

If you find a problem:

1. REPRODUCE THE ISSUE
   - Write down exact steps to reproduce
   - Note any error messages
   - Check browser console (F12)

2. COLLECT DEBUG INFO
   - Browser console errors (F12 → Console)
   - Server logs (look at terminal)
   - Network requests (F12 → Network tab)
   - Database state (if you can check)

3. DOCUMENT FINDINGS
   - What were you trying to do?
   - What happened instead?
   - What error message did you see?
   - Screenshots/logs?

4. TEST AGAIN
   - Try with different accounts
   - Try in private/incognito window
   - Try hard refresh (Ctrl+F5)
   - Try different browser
