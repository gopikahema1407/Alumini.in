================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Admin Dashboard Not Showing After Login
SOLUTION:
  1. Did you execute the SQL migration? (db/add_admin_role.sql)
  2. Check Supabase: SELECT role FROM users WHERE email = 'mohansampath098@gmail.com'
  3. Should show: role = 'admin'
  4. Clear browser cache (Ctrl+Shift+Delete)
  5. Logout and login again

PROBLEM: "⋯" Button Not Appearing on Posts
SOLUTION:
  1. Refresh page (Ctrl+R)
  2. Check browser console (F12 → Console)
  3. Look for errors
  4. Verify public-feed.html loads (check Network tab)

PROBLEM: Delete Post Returns "Unauthorized" Error
SOLUTION:
  1. You must be the post owner
  2. Check: Is it your post?
  3. Or login as admin account to delete any post

PROBLEM: SQL Migration Errors
SOLUTION:
  1. Copy ENTIRE file contents (all SQL)
  2. Paste into Supabase SQL Editor
  3. Make sure file ends with semicolons
  4. Check for syntax errors
  5. Try running line by line

PROBLEM: Server Not Running
SOLUTION:
  1. Check terminal: Is "python app.py" running?
  2. Look for "[AlumniX Server] Running on http://127.0.0.1:5000"
  3. If not running, execute: python app.py (in AluminiX directory)
  4. Try: http://localhost:5000 in browser

PROBLEM: POST Endpoints Return 403
SOLUTION:
  1. Verify you're logged in
  2. Verify API request includes user_id parameter
  3. Check browser console for full error message
  4. Make sure POST /api/posts/<post_id> endpoint exists

API ENDPOINTS
================================================================================

Admin Dashboard:
  GET /api/admin-dashboard?user_id=<uuid>
  Response: Stats, recent activity, top users
  Auth: Requires admin role

Delete Post:
  DELETE /api/posts/<post_id>
  Body: {"user_id": "<uuid>"}
  Auth: Post owner or admin

Report Post:
  POST /api/posts/<post_id>/report
  Body: {"user_id": "<uuid>", "reason": "..."}
  Auth: Any logged-in user
